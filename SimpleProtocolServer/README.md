# 简易报文 TCP 服务器

这是从 AutoCrosstalk 中独立出来的 .NET 8 WinForms 应用，不包含切图、亮色度或复杂 Target 参数。程序启动后自动监听 `127.0.0.1:9527`，另一端应作为 TCP 客户端连接。

## 使用方法

1. 在“命令类型”中选择需要的命令。
2. 切换配方、保存配方和获取焦距时，在参数框输入配方名或 VID。
3. “发送报文（可编辑）”会先生成选中命令的报文，也可手工修改。每次只填写一条以 `&|` 开始、以 `|@` 结束的报文。
4. 点击“发送一次”，将发送当前编辑框中的报文。
5. 点击“加入循环列表”可以依次添加多条不同报文；可删除、清空，或双击列表项回填到编辑框。
6. 设置“间隔(分)”后点击“开始定时发送”。程序会立即发送列表第一条，之后按间隔发送下一条，到达末尾后从第一条继续循环。

客户端断开或停止监听时，定时发送会自动停止。同一时间只能有一个程序监听 `9527` 端口。

## 设计器编辑

在 Visual Studio 中右键 `MainForm.cs`，选择“查看设计器”。所有文本框、按钮、下拉框、数值框、标签和计时器都定义在 `MainForm.Designer.cs` 中。

## 编译

```powershell
dotnet build SimpleProtocolServer\SimpleProtocolServer.csproj -c Release
```
