# AutoCrosstalk 测试项 TCP 工具

这是一个 .NET 8 WinForms 程序。界面按参考图采用左侧测试项、右侧图像识别/眼位属性的布局，顶部是 TCP 服务器状态栏，右下角显示发送预览和接收日志。程序可以读取文件夹内的全部图片并逐张完成亮色度测试，也支持手动或定时循环投图。

## 打开和运行

1. 使用 Visual Studio 2022 或更高版本打开 `AutoCrosstalk.sln`。
2. 将 `AutoCrosstalk` 设为启动项目并运行。
3. 程序启动后自动监听 `127.0.0.1:9527`；另一端必须作为 TCP 客户端连接该地址和端口。
4. 客户端连接后，编辑测试数据并点击“确定（发送）”。尚无客户端时会生成报文预览，但不会发送。

## 定时循环发送报文

客户端连接后，在主界面设置“发送间隔(分钟)”，再点击“开始定时发送”。间隔支持 `0.1` 到 `1440.0` 分钟；启动时会立即发送一次，之后按设定间隔循环发送。每轮都根据当前文本框、组合框和单选框重新生成 `Target` 报文，所以参数改动会在下一轮生效。

再次点击“停止定时发送”可停止。TCP 客户端断开或服务器停止监听时，定时发送也会自动停止。

## 图片亮色度自动测试

1. 启动程序，等待另一端客户端连接到 `127.0.0.1:9527`。
2. 保持 `Target`、`OK` 和 `1 - 亮度`，填写亮色度曝光、阈值、眼位等参数。
3. 点击“批量亮色度测试”。
4. 默认目录为 `D:\work_file\串扰\全屏 20260717`。程序会加载目录内全部 PNG、BMP、JPG、JPEG 图片，数量不作限制。
5. 投影模式默认使用参考项目的“扩展屏幕”，设置切图等待时间后点击“开始批量测试”。

自动流程依据《TCP通讯协议3.0》执行：

```text
批次开始：发送 &|Target|...|@ → 等待 &|Target|OK|@
每张图片：转为 BMP 并切换桌面壁纸 → 刷新扩展屏模式 → 等待画面稳定 → 发送 &|Meas|A|A|@
设备开始：接收 &|Meas|A|A|Run|@
单图完成：接收 &|Meas|A|OK|@ → 切换下一张
```

`Target` 返回 `NG`、测试超时或 TCP 断开时默认停止；也可以勾选“单图失败后继续”。勾选“完成后恢复原桌面”后，正常完成、停止或异常退出批次都会尝试恢复测试前的壁纸。

“测试切换下一张”用于手动逐张投图，不需要启动 TCP 测试。“定时间隔(s)”用于设置自动切图间隔，点击“开始定时投图”后会立即显示第一张，再按指定间隔循环文件夹内的全部图片；再次点击同一按钮即可停止。

## 设置保存

主界面的 Target、测试类型、测试名称、图卡、点模板、两组识别选项、曝光参数、眼位、定时发送间隔等，以及批量界面的图片目录、投影模式、等待时间、超时、复选框和定时间隔，都会在窗口关闭时保存，下次启动自动恢复。设置文件位于：

```text
%LOCALAPPDATA%\AutoCrosstalk\settings.json
```

桌面切换参考 ZJS2310 的实现：源图片先缓存为 24 位 BMP，再调用 Unicode `SystemParametersInfo`，随后调用 `SetDisplayConfig` 刷新扩展屏模式。参考目录 `D:\test_file_2026.6\HY-SJ文件夹\ZJS2310` 仅被读取，没有改动。

命令行编译：

```powershell
dotnet build AutoCrosstalk.sln -c Release
```

本地协议与 TCP 回环测试（无需外部服务器）：

```powershell
dotnet run --project AutoCrosstalk.SmokeTests -c Release
```

## 报文映射

程序使用 UTF-8 编码，完整格式为：

```text
&|Target|OK/NG|测试项|测试名称|图类型|图卡名称|点模板|曝光模式|识别模式|R曝光|G曝光|B曝光|增益|阈值|眼位模式|指定眼位|@
```

主要枚举值：

- 图类型：`0` = Logical 图，`1` = BMP 图。
- 曝光模式：`0` = 自动曝光，`1` = 手动曝光。
- 识别模式：`0` = 自动识别，`1` = 阈值识别。
- 眼位模式：`0` = 指定眼位，`1` = 中心眼位，`2` = 全眼盒，`3` = 上眼盒，`4` = 中心眼盒，`5` = 下眼盒。

默认界面生成的示例：

```text
&|Target|OK|1|brightness|0|White|9|0|1|84848|74434|143383|0|0.1|1|5,9,13|@
```

“曝光模式”和“识别模式”是两个互不影响的单选组。任一文本框、组合框或单选按钮变化时，“发送预览”都会立即重新生成；上例中的第 8 个数据字段 `0` 表示自动曝光，第 9 个数据字段 `1` 表示阈值识别。

TCP 是字节流，程序的接收循环会依据 `&|` 和 `|@` 自动处理拆包与粘包。收到的最后一条完整报文可以通过“载入最后报文”回填到界面。

## 在设计器中编辑

在“解决方案资源管理器”中右键 `MainForm.cs` 或 `BatchTestForm.cs`，选择“查看设计器”。文本框、按钮、单选框、组合框、列表和坐标都定义在对应的 `.Designer.cs` 文件中，可在属性窗口继续修改。协议、TCP、桌面切换和批量状态机分别位于 `Protocol`、`Networking`、`Automation` 目录。
